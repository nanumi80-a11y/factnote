# 팩트노트

지역 언론사 기자를 위한 팩트체크 도구입니다. 주장 한 문장(또는 기사 초고, 보도자료, 사진, PDF 등 문서)을 넣으면, 정부·공공기관·통계·언론 자료를 찾아 근거로 보여 주고 AI가 6단계로 판정합니다.

**판정은 참고용입니다.** 기자가 근거를 직접 확인하고 "데스크 확정"에서 최종 판정을 내려야 합니다.

## 기능

- 한 문장 검증: 근거를 최대 5건 찾아 "사실 / 대체로 사실 / 절반의 사실 / 대체로 사실 아님 / 사실 아님 / 판단 유보" 중 하나로 판정
- 판정 이유마다 근거 원문 한 줄을 붙이고, 그 글이 근거에 정말 있는지 프로그램이 대조
- 정부·공공기관·통계 자료를 먼저 찾고, 주장의 연도 이후 자료와 날짜(1년 넘으면 "오래된 자료")를 표시
- 모호한 주장은 다듬은 문장 후보 제안, 여러 주장이 섞인 문장은 나눠서 판정하고 전체 판정을 따로 표시
- 기사 점검: 기사·보도자료(주소, 붙여넣기, PDF·docx·hwpx·txt 파일)에서 확인할 문장만 뽑아 판정 색을 원문에 표시
- 사진 점검: 사진 파일 기록(EXIF)을 읽고 AI가 조작·합성 의심 지점을 알려 줌 (진짜라고 단정하지 않음)
- 영상 점검: 영상에서 장면을 뽑아 AI가 의심 지점을 알려 주고, 파일 기록·편집 흔적(트랙 길이, 소리 끊김, 장면 전환)을 계산하며, 원하면 소리를 글자로 옮겨(이 컴퓨터에서 처리) 말한 내용을 검증. 딥페이크·AI 영상을 걸러내지는 못하고 외부 탐지 도구를 안내함
- 문서 첨부: PDF·docx·hwpx·txt를 근거로 추가
- 취재 도우미(챗봇): 화면 오른쪽 아래 버튼. 대화로 주장 판정, 기사 문단에서 확인할 문장 고르기, 방금 판정에 대한 질문, 검색 범위(정부 자료만·최근 한 달 등) 지정
- 음성 입력(Chrome·Edge), 데스크 확정과 검증 기록 표, 엑셀(CSV) 내려받기

## 사용하려면

1. **Claude API 키**와 **Tavily API 키**가 필요합니다. 설정 창에 입력하면 **이 브라우저에만** 저장됩니다. 이 저장소의 어떤 파일에도 키는 들어 있지 않습니다.
2. Tavily는 브라우저에서 바로 부를 수 없어서 **중계 서버**가 필요합니다. 둘 중 하나를 고르세요.
   - **내 컴퓨터에서 실행(가장 쉬움)**: [Node.js](https://nodejs.org)를 설치하고 `start.bat`(윈도우)을 실행하면 `http://localhost:8787`이 열립니다. 이 창을 닫으면 멈춥니다. GitHub Pages로 연 화면에서도 이 중계 서버가 켜져 있으면 그대로 동작합니다.
   - **Cloudflare Worker**: `cloudflare-worker.js`를 본인 Cloudflare 계정에 올린 뒤, 나온 주소를 설정의 "중계 주소"에 적습니다.

## 알아둘 점

- 입력한 글, 사진, 문서는 분석을 위해 Anthropic(Claude)으로 전송됩니다. 음성 입력은 브라우저의 음성 인식 서비스로 전송됩니다.
- 검증 기록과 데스크 확정 기록은 사용하는 브라우저에만 저장됩니다. 중요한 기록은 CSV로 내려받아 보관하세요.
- 옛 한글(.hwp), 옛 Word(.doc) 파일은 읽지 못합니다. PDF나 .hwpx, .docx로 저장해 올려 주세요.
